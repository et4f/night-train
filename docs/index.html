    怎么算「一晚」：发车时间落在你设定的傍晚区间、到达时间落在清晨区间，且全程跨过零点（在车上过夜）。 「夜宿指数」由 发车时间 34% + 抵达时间 40% + 车上时长 26% 加权得出，90 分以上是理想节奏。
    两种查法：切到「从这儿出发」，看我在的城市能睡到哪些地方；切到「到这儿来」，看哪些城市能一夜睡到这儿。
